## How GitHub attribution works

GitHub's [contributors graph](https://github.com/parkyountaek/own-the-change/graphs/contributors) reflects eligible commit attribution, not this file or README badges. [Co-authored commits](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors) use an email linked to a GitHub account to count toward that account's contributions. Adding the trailer does not guarantee a separate Codex entry in the Contributors sidebar; we do not invent an account or change the human author to force one.

Feedback, documentation fixes, and reproducible bug reports also help; public acknowledgments beyond commit attribution require the contributor's permission.

Want to help? Start with [good first contributions](CONTRIBUTING.md#good-first-contributions) or the [first-use trial](docs/launch/early-access.md). We do not invent contributors, testimonials, usage counts, or endorsements.
