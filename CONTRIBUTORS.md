# Contributors

Created and maintained by [@parkyountaek](https://github.com/parkyountaek).

GitHub's [contributors graph](https://github.com/parkyountaek/own-the-change/graphs/contributors) is the source for commit attribution. Feedback, documentation fixes, and reproducible bug reports also help; public acknowledgments beyond commit attribution require the contributor's permission.

Want to help? Start with [good first contributions](CONTRIBUTING.md#good-first-contributions) or the [first-use trial](docs/launch/early-access.md). We do not invent contributors, testimonials, usage counts, or endorsements.
