# Generic agent instructions

Read `../../docs/protocol/understanding-protocol.md` before using Own The Change. It is the only common learning-rule source.

Use the current repository's actual `git diff` and actual test output. Do not infer understanding from passing tests, agent confidence, or missing user input. Store records under `docs/ai-understanding/YYYY-MM-DD/<task-id>.md` and run `python3 scripts/validate_record.py <record>` after writing one.
